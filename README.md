# English A1→A2 Telegram Bot
1. `pip install -r requirements.txt`
2. `.env.example` ni `.env` ga nusxalang, BOT_TOKEN ni (@BotFather) yozing
3. `python bot.py`
4. Mini App (ixtiyoriy): `webapp/` papkasini HTTPS hostingga (GitHub Pages, Netlify) yuklang, URL ni .env dagi WEBAPP_URL ga yozing.
Dars qo'shish: bot.py dagi UNITS ro'yxatiga yangi lug'at qo'shing.
